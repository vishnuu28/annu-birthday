# ✨ Annu's Birthday Galaxy ✨
### 💖 A Special 30-Day Birthday Month Website for Anakha (Annu / Babydoll)

A playful, animated, interactive romantic website built with pure HTML5, CSS3, and modern JavaScript. Specially crafted for **Anakha** to celebrate her entire birthday month from **November 1st to November 30th**!

---

## 🌟 What's Inside:
1. **🏹 Cupid & Cap's Heart Shooter**:
   - An interactive bow & arrow game where she aims and shoots at floating hearts, Captain America vibranium shields, Taylor Swift golden stars, and Biryani pots!
   - Features real-time particle explosions and custom romantic surprises upon every hit.

2. **🏃‍♀️ The Impossible "NO" Game**:
   - A playful question asking if she admits to being the prettiest, sweetest Babydoll in the universe.
   - When she hovers or touches **"No"**, the button teleports away with hilarious objections (*"Error 404: 'No' not found!"*, *"I'll bribe you with Biryani!"*, *"Deepika wouldn't say no to Ranveer!"*).
   - Every dodge grows the **"YES"** button until she clicks it, triggering grand victory confetti!

3. **📅 30 Days of Babydoll (November Advent Calendar)**:
   - 30 distinct daily interactive surprise envelopes spanning **Nov 1st to Nov 30th**!
   - Tailored specifically to Annu's favorites:
     - 🛡️ **Captain America**: "I can love you all day", loyalty oaths, multiverse declarations.
     - 🎵 **Taylor Swift**: Eras vibes, *Lover*, *Fearless*, *1989*, *Daylight* lyrics.
     - 💃 **Ranveer & Deepika**: Romantic Bollywood dialogues (*Bajirao Mastani*, *Ram-Leela*).
     - 🍲 **Biryani Vouchers**: Dum Biryani feast date tickets, midnight treat coupons.
     - 👑 **Grand Finale (Nov 30)**: An emotional, beautiful Happy Birthday letter!
   - Includes an **"Unlock All Days (Preview Mode)"** button so you can explore all cards at any time.

4. **🍲 Babydoll's Biryani & Love Catcher**:
   - An arcade mini-game where Annu controls a golden bowl to catch falling steaming Biryani pots, Marvel shields, and Swiftie records.

5. **💌 100 Reasons Why Annu is Irreplaceable**:
   - Tap the glowing crystal heart to generate endless romantic and funny reasons why she's loved.

6. **🎂 Blow The Birthday Candles**:
   - Layered birthday cake with animated flickering flames that can be blown out individually or all at once, launching fireworks and playing the synthesized Happy Birthday melody!

7. **🎶 Zero-Dependency Web Audio Synth**:
   - Plays delightful chimes, bow twangs, fanfare, and music-box tunes natively via Web Audio API (no broken audio links).

## 🚀 How to Host on GitHub Pages for Free (Takes 2 Minutes)

Because this website uses pure HTML, CSS, and JS (with no external server or database needed), it runs **100% free forever on GitHub Pages**!

### Step 1: Create a New GitHub Repository
1. Go to [github.com/new](https://github.com/new).
2. Name the repository something sweet, for example: `birthday-annu` or `babydoll-birthday`.
3. Set it to **Public** (required for free GitHub Pages).
4. Click **Create repository**.

### Step 2: Push the Files to GitHub
Open your terminal inside this folder (`d:\birthday2026`) and run:

```bash
git add .
git commit -m "Happy Birthday Month Babydoll Annu"
git remote add origin https://github.com/Vishnu4-28/YOUR-REPO-NAME.git
git push -u origin main
```
*(Replace `YOUR-REPO-NAME` with whatever name you chose in Step 1).*

### Step 3: Turn on GitHub Pages
1. In your GitHub repository, click on **Settings** (gear icon at the top).
2. In the left sidebar, click on **Pages**.
3. Under **Build and deployment > Branch**:
   - Select **Branch: `main`**
   - Folder: **`/ (root)`**
4. Click **Save**.
5. Within 60 seconds, GitHub will give you a live link like:
   👉 **`https://Vishnu4-28.github.io/YOUR-REPO-NAME/`**

Share this link with Annu, and she can play it directly on her phone, laptop, or tablet! 💖
